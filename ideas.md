# Chosen Approach: Velvet Webring

## Design Movement

**Neo-Geo personal-web revival** with the tactile, friendly character of late-1990s and early-2000s profile pages. The interface intentionally uses centered composition, framed modules, bevels, and small utility details to honour the requested old-style classic UI.

## Core Principles

1. **Tactile surfaces:** Every panel and link feels pressable through crisp outlines, inset highlights, and weighted shadows.
2. **Sincere personal presence:** The avatar, about copy, Discord identity, and open web links remain the visual focus.
3. **Legible retro density:** Small interface details enrich the atmosphere but never compete with readability or touch targets.
4. **One handcrafted page:** The entire profile reads as a coherent personal homepage, not a collection of app cards.

## Color Philosophy

The composition begins in a near-black **oxblood maroon** to create a dusk-like desktop backdrop. Dusty dark-pink panels add warmth, while pale rose highlights mimic aged monitor phosphor and give the UI its familiar early-web glow without turning neon. Cream text is used sparingly for soft, dependable contrast.

## Layout Paradigm

The page is a **centralized profile terminal**: a tall, narrow, framed interface on an open patterned desktop. The avatar occupies a circular crest above the identity line; profile information sits in a compact introduction module; links form a single stacked directory framed by ornamental separator bars. This deliberate central placement follows the requested profile layout.

## Signature Elements

1. A repeating, low-contrast checker-and-star desktop texture.
2. Double-line maroon frames with top-left highlights and lower-right shadows.
3. Tiny interface labels, square status lights, and ornamental divider rules.

## Interaction Philosophy

Links feel like real old desktop controls: on hover they brighten, lift by a few pixels, and reveal a small directional marker. On press they settle inward. Keyboard focus uses a clear pale-pink perimeter without losing the retro visual language.

## Animation

The profile modules enter with a short 40ms stagger and a soft vertical settle. Link interactions use only opacity and transforms with a snappy custom easing under 180ms. Decorative elements remain still; visitors who prefer reduced motion see the completed page immediately.

## Typography System

**Special Elite** supplies the display language for the personal name, status notes, and small UI labels. **IBM Plex Mono** handles all navigation and body text for a clean yet era-appropriate system feel. The name is large, tracked tightly, and always treated as a visual anchor; links are medium-weight and uppercase-leaning through letterspacing rather than excessive font size.

## Brand Essence

**A personal link home for an aspiring full-stack developer, Discord regular, and Bloxd.io player who likes the handcrafted web.**

Personality: **curious, nostalgic, direct.**

## Brand Voice

The voice is concise, candid, and quietly self-aware—like a personal webpage maintained with care. Headlines sound like labels on a beloved web directory; CTAs name a destination plainly.

Example lines:

> `a work in progress, on the web and off.`

> `choose a room to visit →`

## Wordmark & Logo

The wordmark treats the profile name as a stamped label, spaced around a small four-point computer-cursor emblem. The logo mark is a chunky, text-free rose cursor/star hybrid within a maroon square—designed to work as both a header emblem and favicon.
